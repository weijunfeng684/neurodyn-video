# Latent State-Space Analysis of Action Videos with GRU Dynamics

This project studies action videos from a **temporal modeling** perspective rather than a purely frame-based classification perspective.  
A GRU-based recurrent model is used to process video feature sequences, and two different observation encoders are compared:

- **Handcrafted temporal frame features**
- **Pretrained ResNet18 frame embeddings**

Besides action classification, the project also analyzes the learned hidden-state structure through:

- confusion matrices
- PCA of final hidden states
- PCA trajectories of full hidden-state sequences

The main idea is to treat a video as a **sequence of observations generated by evolving latent behavioral states**.

---

## Motivation

In many standard video recognition pipelines, the main objective is simply to improve classification accuracy.  
This project uses a slightly different viewpoint:

- a video is treated as a **time series**
- the GRU hidden state is treated as a **latent temporal representation**
- hidden-state geometry is analyzed as a **state-space structure**

This makes the project closer to a **state-space / dynamical-systems perspective** than a purely frame-based action recognition baseline.

The project focuses on two questions:

1. Can action videos be modeled as trajectories in a latent state space?
2. How does the quality of the observation encoder affect the learned latent dynamics?

---

## Dataset

The project uses a **3-class subset** of the Weizmann action dataset:

- `walk`
- `bend`
- `jump in place`

Videos are split at the **video level** into:

- train
- validation
- test

This repository is intended as a **small proof-of-concept** for temporal modeling and latent-state analysis, not as a large-scale benchmark study.

---

## Method

### 1. Handcrafted temporal features + GRU

Each video is converted into a sequence of lightweight frame-level temporal features, including:

- mean brightness
- brightness standard deviation
- grayscale histogram
- frame difference magnitude
- optical-flow magnitude summary

The resulting feature sequence is then fed into a GRU classifier.

This serves as a lightweight baseline observation encoder.

---

### 2. ResNet18 frame embeddings + GRU

Each video is uniformly sampled to **16 frames**.

A pretrained **ResNet18** is used as a frame encoder, producing a **512-dimensional feature vector** per frame.  
The resulting feature sequence is then modeled by the same GRU architecture.

This provides a stronger observation encoder for comparison against the handcrafted-feature baseline.

---

### 3. Latent-state analysis

To move beyond pure classification, the GRU hidden states are further analyzed using:

- **confusion matrices**
- **PCA of final hidden states**
- **PCA trajectories of full hidden-state sequences**

This allows the project to compare not only classification accuracy, but also the geometry of the learned latent representations.

---

## Results

| Feature type | Temporal model | Test accuracy |
|---|---|---:|
| Handcrafted temporal features | GRU | 0.3333 |
| ResNet18 frame embeddings | GRU | 1.0000 |

### Interpretation

- The handcrafted-feature baseline captures some temporal structure, but shows systematic confusion across action classes.
- Replacing handcrafted features with pretrained visual embeddings greatly improves separability and classification performance in the current 3-class Weizmann setting.
- Hidden-state PCA and trajectory plots suggest that stronger observation encoders also induce cleaner latent-state geometry.

## Notes on interpretation

This project should be read as a **small controlled prototype**.

Its main value lies in comparing:

- weaker handcrafted observation features
- stronger pretrained visual observation features

under the same recurrent temporal model.

The project shows that observation quality strongly affects both:

- classification performance
- latent-state separability
- hidden-state trajectory structure

---

## Limitations

- The dataset is very small, so the reported performance should be interpreted cautiously.
- Only a 3-class subset of the Weizmann dataset is used.
- The handcrafted-feature baseline is intentionally lightweight and not meant to compete with strong modern video encoders.
- The ResNet-based model performs very well in this small controlled setting, but this should not be over-interpreted as evidence of strong real-world generalization.
- The computational-neuroscience connection here is methodological rather than biological: the project borrows a latent-state / state-space perspective, but does not model real neural recordings.

---

## Possible next steps

- replace GRU classification with a more explicit latent dynamical system
- analyze within-video phase transitions more explicitly
- compare additional observation encoders
- evaluate on more action classes or a larger dataset
- study hidden-state trajectories under perturbations or temporal augmentation

---

## Summary

This repository implements a compact temporal modeling pipeline for action videos and compares two observation encoders under the same GRU-based recurrent model.

The main takeaway is:

- **handcrafted temporal features** lead to weak separability and limited performance
- **pretrained ResNet18 embeddings** produce much cleaner latent geometry and much stronger classification performance

Overall, the project serves as a small prototype for studying the relationship between **video observations**, **recurrent latent states**, and **state-space structure**.
